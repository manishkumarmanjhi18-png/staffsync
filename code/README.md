# StaffSync - HR Management (MERN)

Requirements: Node.js 18+ and MongoDB running locally (or put an Atlas URL in backend/.env).

Terminal 1:  cd backend && npm install && npm start
Terminal 2:  cd frontend && npm install && npm run dev
Open http://localhost:5173
